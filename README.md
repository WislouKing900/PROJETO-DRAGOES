# 🐉 Projeto Dragões 🐉

Bem-vindo ao **Projeto Dragões**, um repositório vivo e em constante evolução dedicado ao estudo e à prática de desenvolvimento web. Este projeto serve como meu laboratório pessoal, 
onde aplico e integro novos conhecimentos à medida que avanço na minha jornada como desenvolvedor.

---

## 🛠️ Tecnologias e Conceitos Aplicados

O projeto foi construído e planejado para crescer junto com meus estudos:

* **HTML5 Semântico:** Estruturação correta das páginas e acessibilidade.
* **CSS3:** Estilização avançada, design responsivo e foco em uma estética imersiva.
* **JavaScript (Em expanssão):** Manipulação do DOM, lógica de programação e dinamismo da interface.
* **Banco de Dados & APIs (Em expansão):** Integração com dados estruturados, requisições HTTP e consumo de APIs.

---

## 🗺️ O Propósito do Projeto

Mais do que apenas um site, este repositório é uma linha do tempo prática do meu aprendizado. A ideia é evoluir o sistema iterativamente:
1. Começando com dados locais e estáticos (arrays e objetos).
2. Avançando para estilizações mais complexas e componentes reutilizáveis.
3. Conectando com bases de dados reais e entendendo o fluxo de requisições e respostas (Client/Server).
